Réglages des rôles

Trois façons de choisir les cartes dans la salle d'attente. Les écrans répondent au doigt : touche les rôles pour sentir chaque version.

A · Grille de cartes

Une carte par rôle. Allumée = dans la partie. Seuls les loups ont un compteur.

B · Résumé, puis tiroir

On voit d'abord le paquet proposé. « Modifier » ouvre une liste d'interrupteurs.

C · Éventail de cartes

Les cartes défilent comme dans une main. Celles qui sortent du paquet sont dans la partie.

Partout pareil : les villageois se calculent seuls (joueurs moins rôles), la composition recommandée reste un bouton, et les cartes du milieu apparaissent quand le voleur est allumé.
